Preservation screens

Compare numbers, negation, selected hedges and quantifiers, acronyms and mathematical/citation placeholders. Reject unchanged-word pairs and obvious extraction artifacts. These guards cannot certify semantic equivalence.

Independent curation

Two unfilled reviewer packets are generated for each partition. Curators score the source separately, then assess meaning, fluency and target suitability. Disagreement and uncertain pairs do not become approved training data.

Test quarantine

New test text is absent from this public explorer and remains in the local cache. Independent data curators may review its dedicated packet. Developers must not use those cases for tuning, prompts or threshold selection.

Provenance and distribution

Public records contain IDs, versions, source hashes, intent signals and paper-specific license URLs. Raw paper text and review packets stay in the ignored cache because the source collection has mixed licenses.

Matched stage-two conditions

Token cross-entropy · seed 42 · LR 2e-5 · batch 2 · maximum 300 updates · validation every 25 updates · early stopping after four unimproved checks. Shuffle each training epoch. Reject silent truncation.

Save the selected checkpoint

Validation selects actual saved weights, including step zero. A harmful continuation can retain its parent. Continuation loads matching architecture, tokenizer and weights, then starts a new optimizer. Training does not select on test results.

The old stage-one BART and hybrid used different learning rates. Their continued versions alone cannot isolate an architectural advantage. The direct arms and future matched seeds remain necessary.

05 / Judge useful changes

Measure improvement where it is needed.

Academic tone + meaning

Awaiting real ratings

Independent, blinded output judgments: meaning, academic expression, fluency, positive improvement and major factual errors. Semantic similarity remains a supporting diagnostic.

Effective revision rate

No measured rate yet

Denominator: sources independently judged to need refinement. Both raters must pass all provisional thresholds, with a changed output and no major factual error.

Unnecessary edit rate

Requires suitable-source controls

Denominator: already-suitable sources. A changed output counts as unnecessary only with an explicit reviewer judgment; editing alone is not treated as an error.

Reverse augmentation remains train-only. Synthetic sources must retain the approved academic target, document identity, numbers, hedges, negation and protected technical terms. They need separate review and cannot replace real independent test cases.

The next quality milestone is a set of real held-out before/after model outputs with independent judgments. A lower loss, a shortlist or a synthetic example does not satisfy that milestone.
